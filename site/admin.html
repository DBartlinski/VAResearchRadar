Overview

Daily Update is a daily pipeline that aggregates, scores and publishes Veterans Affairs research publications from PubMed, OpenAlex and Crossref, with funding attribution and a static dashboard.

Dimensions is a benchmark only

Dimensions is not a data source (dimensions.ingest: false in config/settings.yaml). Its exports may not be redistributed, so the public build never reads them.

How a run works

  1. Query PubMed, OpenAlex and Crossref for records within the lookback window.
  2. Drop records with no VA affiliation and no VA funding evidence.
  3. Attribute funding and score each record into High, Medium or Low priority.
  4. Store records in the local database, keeping first-seen dates for the “Added” day pills.
  5. Write the dashboard data files to site/data.

Local setup

  1. Install Python 3.13.
  2. Create and activate a virtual environment. 
    python -m venv .venv
.venv\Scripts\Activate.ps1
  3. Install dependencies. 
    pip install -r requirements.txt
  4. Optionally set NCBI_API_KEY and OPENALEX_API_KEY to raise API rate limits, and set contact_email in config/settings.yaml.

Running the pipeline

Command line

python -m vadaily.pipeline

Local dashboard

Start the Flask app, then open http://localhost:5000 (port set under server.port).

python app.py

The app serves the site folder and provides a refresh endpoint (POST /api/refresh) that runs the pipeline. Refresh requests must be JSON, and only one refresh can run at a time.

Tests

pytest

Publishing

The public site is built and deployed to GitHub Pages by the workflow Build and deploy public site (PubMed + OpenAlex only) in .github/workflows/pages.yml.

Manual republish

In GitHub, open Actions, choose the workflow, and select Run workflow. Changes to static pages in site go live on the next run after they are pushed to main.

Scoring

Each record receives a point total. Totals of 45 or more are High, 25 or more are Medium, and the rest are Low (scoring.tiers).

  • Veteran in title: keywords such as veteran*, military, service member*.
  • Topics: weighted keyword groups, for example suicide prevention, toxic exposures / PACT Act, Million Veteran Program, PTSD, TBI and homelessness.
  • Study designs: randomized trials, meta-analyses, Cooperative Studies Program, large national studies and more. Prefix a keyword with re: to use a raw regular expression.
  • Journal tier: based on OpenAlex 2-year mean citedness, with name overrides in always_top and always_mid.
  • Funding: higher weight for ORD-funded than VA-funded-only work.
  • Penalties: preprints, conference abstracts, editorials and letters, errata, retractions and non-health records.

To tune results, edit the weights or keywords and rerun the pipeline. Scores are recalculated from the stored records.

Dimensions comparison

To compare the tool against a Dimensions export (VA scope, capped at 500 rows):

python -m compare.report "Dimensions comparison\<export folder>" <label>

This writes reports/dimensions-gaps-<label>.csv and reports/dimensions-comparison-<label>.md.

Do not commit Dimensions files

The Dimensions exports, comparison folder and reports are excluded in .gitignore. Keep them out of the repository and the public site.

Troubleshooting

“Added” dates reset

The database cache (data) was not restored. Check the cache step in the workflow run log. The first run after a cache miss treats every record as new.

Rate-limit or empty results

Confirm the NCBI_API_KEY and OPENALEX_API_KEY secrets are set and that contact_email is filled in.

A record is missing

It may be dated before start_date, or lack VA affiliation and funding evidence while require_va_evidence is on. Add an affiliation query to the relevant source if needed.

Refresh returns an error

A 409 means a refresh is already running; a 415 means the request was not JSON. Other failures are logged by the Flask app.

Workflow fails to deploy

Confirm GitHub Pages is enabled for the repository and that the workflow has Pages and ID-token permissions.
